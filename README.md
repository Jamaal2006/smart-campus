# Smart Campus Resource Hub

Full installation instructions and project documentation.

## Installation Instructions
1. Clone this repository using `git clone https://github.com/Jamaal2006/smart-campus.git`
2. Navigate to the project directory.
3. Import the `smart_campus.sql` file to your MySQL database.
4. Configure `database.php` with your database credentials.
5. Set up email configurations in `email.php`.
6. Ensure all necessary directories have appropriate permissions.

## Project Overview
The Smart Campus Resource Hub is a full-stack booking system designed to streamline the management of campus resources. It features:
- QR code generation for easy access to resources
- Dark mode for improved accessibility
- Real-time availability checking for users.

## Getting Started
Use the following files to navigate the application:
- **index.php**: The landing page.
- **login.php**: User login page.
- **register.php**: User registration page.
- **student/dashboard.php**: Student dashboard for managing bookings.
- **admin/dashboard.php**: Admin dashboard for managing resources.

For more information, check out the individual components in the `includes`, `assets`, and `api` folders.
